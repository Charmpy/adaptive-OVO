# Эксперимент 1. Базовая оценка OVO

## Цель

Получить базовые показатели качества и вычислительной стоимости на 2000 кадрах Replica `office0` при `segment_every=10` и `map_every=5`.

## Результат

Построена семантическая карта; обработано 200 кадров — 10% последовательности.

| Показатель | Значение |
|---|---:|
| mIoU / mAcc, % | 24.90 / 32.80 |
| f-mIoU / f-mAcc, % | 42.00 / 54.00 |
| Суммарное время семантики, с | 128.867 |
| Среднее SPF / P95 SPF, с | 0.641 / 0.850 |
| Средняя / пиковая VRAM, ГБ | 11.253 / 11.532 |
| Средняя / максимальная RAM, ГБ | 3.198 / 3.606 |

| Этап | Среднее, с | P95, с | Сумма, с |
|---|---:|---:|---:|
| SAM | 0.448 | 0.640 | 89.530 |
| Сопоставление объектов | 0.074 | 0.103 | 14.818 |
| CLIP | 0.122 | 0.240 | 24.370 |
| Обновление дескрипторов | 0.001 | 0.002 | 0.149 |

Справочные результаты статьи OVO:

| Вариант | mIoU, % | mAcc, % |
|---|---:|---:|
| OVO-mapping | 27.00 | 39.10 |
| OVO-Gaussian-SLAM | 27.10 | 38.60 |
| OVO-ORB-SLAM2 | 25.60 | 39.00 |

В статье оценка выполнена на наборе сцен Replica, а здесь — только на `office0`; прямое сравнение качества некорректно.

## Вывод

Fixed-10 принят как базовая конфигурация. Получение масок SAM занимает 69.5% измеренного времени семантики, поэтому сокращение числа запусков семантического конвейера представляет основной интерес для снижения затрат.

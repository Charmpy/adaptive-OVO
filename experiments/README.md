# Экспериментальное исследование OVO

Цель — оценить влияние периодичности семантической обработки на вычислительные затраты и качество карты. Используются OVO и сцена `office0` датасета Replica. Установка и запуск окружения описаны в [SetupGuide.md](SetupGuide.md).

## Экспериментальный стенд

Среда развёрнута на удалённом GPU-сервере Selectel.

| Параметр | Значение |
|---|---|
| ОС | Ubuntu 24.04.3 LTS, x86_64 |
| CPU / RAM | 8 vCPU / 32 ГБ |
| GPU / VRAM | NVIDIA GeForce RTX 4090 / 24 ГБ |
| Драйвер NVIDIA | 580.65.06 |
| CUDA, поддерживаемая драйвером | 13.0 |
| Python | 3.11.17 |
| PyTorch / CUDA Runtime | 2.5.1+cu124 / 12.4 |

## Метрики и показатели

| Показатель | Назначение |
|---|---|
| mIoU, mAcc | Качество семантической разметки |
| f-mIoU, f-mAcc | Качество с учётом частоты классов |
| Количество обработанных кадров | Частота вызова семантического конвейера |
| `t_sam`, `t_obj`, `t_clip`, `t_up` | Время сегментации, сопоставления объектов, извлечения признаков и обновления дескрипторов |
| Среднее, P95, сумма времени | Типичная длительность, длительность на 95-м процентиле и суммарные затраты |
| VRAM, RAM | Выделенная PyTorch видеопамять и память процесса |
| `spf`, `avg_fps` | Внутренние показатели производительности OVO |

Времена измеряются встроенным профилировщиком OVO с синхронизацией CUDA. Журналы обрабатываются скриптом `analyze_performance.py`, формирующим `performance_summary.json`, `performance_samples.csv`, `timing.png` и `memory.png`.

Суммарная стоимость семантики определяется как сумма измерений `t_sam`, `t_obj`, `t_clip` и `t_up`. Она не равна полному времени запуска или чистому GPU time. Записи `frame_id` относятся к событиям разных этапов: их количество не равно количеству уникальных обработанных кадров. `avg_fps` не следует трактовать как частоту обработки всего входного потока.

## Общий вывод

На `office0` переход от Fixed-10 к Fixed-20 сократил измеренное время семантики на 46.9% и повысил mIoU на 1.80 процентного пункта. Более частая обработка не гарантирует повышения качества; пиковая VRAM остаётся около 11.5 ГБ. Результаты обосновывают дальнейшее исследование адаптивного выбора кадров, но пока относятся к одной сцене и фиксированным периодическим стратегиям.

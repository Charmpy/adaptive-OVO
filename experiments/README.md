# Результаты экспериментов

В данном разделе приведены результаты экспериментов с OVO. Для каждого эксперимента фиксируются цель, используемая конфигурация, команда запуска, основные результаты и ссылки на полученные артефакты.

Конфигурации экспериментов хранятся отдельно в каталоге [`configs/`](./configs/). Это позволяет сохранить точные параметры каждого запуска и обеспечивает воспроизводимость полученных результатов.

Результаты, логи и визуализации хранятся в каталоге [`results/`](./results/).

---

## Эксперимент 0 — проверочный запуск OVO

### Цель

Проверить корректность развёртывания OVO, установленных зависимостей, предобученных моделей и датасета Replica перед проведением полноценных экспериментов.

Для сокращения времени выполнения обработка была ограничена первыми 20 кадрами сцены `office0`.

### Конфигурация

Полная конфигурация эксперимента:

[`configs/exp00_smoke_test.yaml`](./configs/exp00_smoke_test.yaml)

Основные параметры:

- датасет — Replica;
- сцена — `office0`;
- количество кадров — 20;
- `segment_every` — 10;

### Запуск

```bash
python run_eval.py \
    --dataset_name Replica \
    --experiment_name exp00_smoke_test \
    --run \
    --scenes office0
```

### Результат

Проверочный запуск успешно завершён. OVO корректно загрузил датасет и нейросетевые модели и выполнил обработку заданной последовательности.

Основные показатели:

| Метрика | Значение |
|---|---:|
| Средняя частота обработки | 0.441 FPS |
| Среднее время SAM | 0.635 с |
| Среднее время CLIP | 0.725 с |
| Среднее время обработки объектов | 0.378 с |
| Среднее использование VRAM | 8.64 GB |
| Максимальное использование VRAM | 10.77 GB |
| Полное время запуска | 50.70 с |

Логи и визуализации:

[`results/exp00_smoke_test/`](./results/exp00_smoke_test/)

## Эксперимент 1 — базовый запуск OVO на Replica office0

### Цель

Получить базовые показатели качества семантического картографирования и вычислительной производительности OVO на полной последовательности `office0` датасета Replica.

Полученные результаты используются в качестве baseline для последующего исследования влияния частоты семантической обработки на качество карты и вычислительные затраты.

### Конфигурация

Полная конфигурация эксперимента:

[`configs/exp01_replica_office0_fixed10.yaml`](./configs/exp01_replica_office0_fixed10.yaml)

Основные параметры:

- датасет — Replica;
- сцена — `office0`;
- количество кадров — 2000;
- политика обработки — фиксированная;
- `segment_every` — 10;


### Запуск

Построение семантической карты:

```bash
python run_eval.py \
    --dataset_name Replica \
    --experiment_name exp01_replica_office0_fixed10 \
    --run \
    --scenes office0
```

Сегментация эталонного облака точек:

```bash
python run_eval.py \
    --dataset_name Replica \
    --experiment_name exp01_replica_office0_fixed10 \
    --segment \
    --scenes office0
```

Вычисление метрик:

```bash
python run_eval.py \
    --dataset_name Replica \
    --experiment_name exp01_replica_office0_fixed10 \
    --eval \
    --scenes office0
```

### Результаты

| Метрика качества | Значение |
|---|---:|
| mIoU | 24.90% |
| mAcc | 32.80% |
| f-mIoU | 42.00% |
| f-mAcc | 54.00% |

| Метрика производительности | Значение |
|---|---:|
| Средняя частота обработки | 0.975 FPS |
| Среднее время SAM | 0.454 с |
| Среднее время CLIP | 0.126 с |
| Среднее время обработки объектов | 0.072 с |
| Среднее использование VRAM | 11.253 GB |
| Максимальное использование VRAM | 11.53 GB |
| Максимальное использование RAM | 3.58 GB |

Полученные показатели принимаются в качестве базовой точки `fixed-10` для дальнейшего сравнения различных политик семантической обработки.

# Обзор современных подходов

В существующих исследованиях выбор ключевых кадров для семантического картографирования реализуется на основе различных критериев, определяющих необходимость обработки очередного наблюдения. Рассматриваемые подходы можно разделить на три группы:

## Выбор ключевых кадров обусловленный геометрией.

 В OVO (Open-Vocabulary Online Semantic Mapping for SLAM) [1] построение трёхмерной семантической карты выполняется асинхронно по RGB-D ключевым кадрам, поступающим от базовой SLAM-системы. Для формирования семантического представления используются SAM2.1 [2] и SigLIP [3], обеспечивающие сегментацию наблюдений и извлечение визуально-языковых дескрипторов. Отбор кадров для семантической обработки осуществляется с фиксированной периодичностью из ключевых кадров, поступающих от SLAM-пайплайна, в виде ORB-SLAM3[4], без непосредственной оценки их семантической информативности. Преимуществами подхода являются модульность и независимость семантического конвейера от геометрической локализации, недостатками - избыточная обработка повторяющихся наблюдений и возможность пропуска информативных кадров при фиксированной периодичности отбора.

В RADIO-ViPE [5] ключевые кадры выбираются на основе относительного движения камеры, оцениваемого посредством взвешенного плотного оптического потока. Кадр включается в граф факторов при превышении заданного порога движения. Для выбранных кадров вычисляются нейросетевая глубина и плотные визуально-семантические признаки RADSeg [6], используемые при оптимизации траектории и построении карты. Таким образом, выбор кадров позволяет ограничивать количество вычислительно затратных операций, однако ориентирован преимущественно на обеспечение геометрической локализации и не учитывает непосредственно вклад наблюдений в качество семантического представления.

## Выбор ключевых кадров на основе пространственного покрытия

 В работе KeySG [7] исследуется задача сохранения пространственной и визуальной информации при сокращении количества кадров, используемых для формирования трёхмерного графа сцены. Авторы предлагают кластеризацию поз камеры посредством HDBSCAN[8] и сравнивают её с шестью стратегиями: равномерной и случайной выборкой, кластеризацией визуальных признаков DINOv2 [9], адаптивным DBSCAN, локальной и глобальной оптимизацией совместной видимости объектов.

## Выбор ключевых кадров обусловленный семантически
В FOUND-IT [10] предложен подход к построению иерархического трёхмерного графа сцены с отложенной семантической обработкой. Геометрическое картографирование осуществляется посредством VGGT-SLAM 2.0 [11], где ключевые кадры выбираются на основе параллакса. Для каждого ключевого кадра вычисляется визуально-языковой дескриптор, сохраняемый в памяти системы. При поступлении текстового запроса кадры ранжируются по косинусному сходству их дескрипторов с запросом, после чего релевантные наблюдения направляются в SAM3 для сегментации объектов. Обработка дополнительных кадров выполняется с учётом видимости ранее обнаруженных объектов. Такой подход позволяет сократить количество запусков сегментационной модели и формировать детальное семантическое представление по мере поступления запросов. Однако отбор кадров для семантической сегментации зависит от конкретного запроса, тогда как при построении универсальной карты с открытым словарём будущие запросы заранее неизвестны.

В качестве базового подхода для проведения исследования выбран OVO [2], обеспечивающий построение трёхмерного семантического представления с открытым словарём на основе RGB-D ключевых кадров. Его модульная архитектура позволяет исследовать стратегии выбора кадров для семантической обработки независимо от алгоритма оценки траектории камеры. Модели сегментации и извлечения визуально-языковых признаков остаются неизменными.
